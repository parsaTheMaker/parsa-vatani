# Parsa Vatani — Portfolio

Static GitHub Pages build of Parsa Vatani's personal portfolio.

## Publish

Upload the **contents of this repository** to the `main` branch of
`parsaTheMaker/parsa-vatani` (keep `index.html`, `.nojekyll`, `assets/`, and the
media files at the repository root). In **Settings → Pages**, select
**Deploy from a branch**, then choose **main** and **/(root)**.

The site is configured for:

`https://parsathemaker.github.io/parsa-vatani/`
